# M4 — Residual analysis (the heart of Paper 1)

**Verdict: after the best-fitted linear operator, the residual Δ is statistically indistinguishable from noise for a learnable predictor.** The plan's pre-written negative branch applies: *"After proper alignment, residuals are statistically indistinguishable from noise; projection + brief fine-tuning captures everything learnable."* Faint spectral non-randomness exists but carries no layer-specific, predictable signal. Every test ran against matched controls.

**Δ definition (design decision, option 1):** Δ(l, type) = W_410M − A·W_1.4B·Bᵀ with the shared fitted operator per type — the *strongest-alignment* condition, so whatever remains is what no single linear size-map can explain.

## Test 2 — Cross-layer consistency

Mean pairwise cosine of vectorized Δ across layers: **≈ ±0.0002 in every type**, identical to the shuffle control. **No shared direction across layers.**

## Test 3 — Predictor (decisive)

Patch predictor R(Ŵ patch + type/layer/position) → Δ patch; trained on 18 layers, scored on 6 stratified held-out layers as error reduction vs predicting zero; control = identical training with Δ shuffled across layers; 1000-bootstrap CI on the real−control gap.

| Model | reduction | shuffle control | gap CI95 | p |
|---|---|---|---|---|
| linear | −0.0004 | −0.0004 | [−0.0000, −0.0000] | 0.99 |
| MLP-512 | −0.0003 | −0.0003 | [−0.0000, −0.0000] | 1.00 |

**Zero learnable signal** — the predictor cannot beat predicting-zero at all, and real vs control are indistinguishable. Note the reconciliation with Test 1: the spectral deficit is a *generic* statistical trace (e.g., mild row/column-norm heterogeneity), not a correspondence between Ŵ and Δ that a model can exploit.

## Test 4 — Transfer (held-out pair 410M→160M)

Pair-B operators fit at rel. err 0.56–0.74 (better than pair A — smaller width gap). R trained on all pair-A layers, evaluated on pair B:

| Model | B-reduction | shuffle control | p |
|---|---|---|---|
| linear | −0.0004 | −0.0004 | 1.00 |
| MLP-512 | −0.0003 | −0.0002 | 1.00 |

**No transfer** — consistent with Test 3 (nothing to transfer).

## Test 5 — Behavioral

Assembled 410M with operator-projected matrices (real 410M biases/LNs/embeddings — an ablation isolating the 6 matrix types); wikitext-103 ppl:

| Model | ppl |
|---|---|
| operator matrices | 35,212 |
| operator + R correction | 34,373 |
| (real 410M / random init, M3) | 15.6 / 65,962 |

The correction nudges ppl ~2% — both variants remain non-functional. Notable side-result: operator-projected **matrices alone score better than random init** (35k vs 66k) once biases/LNs/embeddings are real — unlike M3's fully-projected model (181k). Caveat: R's corrections on the 18 training layers are partly memorized; held-out layers carry genuine predictions.

## Interpretation (Paper 1 skeleton)

1. **M2:** representations align strongly across sizes (R²=0.84); weights align weakly.
2. **M3:** dense weight projection is functionally destructive zero-shot (structure-mixing); the fitted linear operator explains ≤ ~30% of weight variance.
3. **M4:** what the linear operator misses is **unpredictable** — no spectral direction shared across layers, no patch-learnable mapping, no cross-pair transfer; only a faint generic spectral fingerprint.

**Conclusion:** within a model family, the *sizes share representation geometry but not parameter solutions*. The information a size-conversion cannot linearly capture behaves as noise — so conversion value must come from **initialization + brief fine-tuning** (M5's recovery-curve question), not from a learned zero-shot correction.

**Caveats / next rung (the escalation ladder):** this null is w.r.t. (a) option-1 Δ — the operator already absorbed all linearly-explainable structure; (b) patch-local predictors (linear, MLP-512). Option 3 — Δ against a **structured selection map** (subcloning-style) — is the next rung and coincides with M5's baseline work. A richer predictor (whole-matrix, spectral-feature) is possible but unmotivated given the flat controls.
