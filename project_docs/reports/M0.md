## Compute environment

Development is on a Mac (git source-of-truth); all runs execute on the **DGX Spark** (host in `.spark.env`) over SSH via `./spark.sh`. Code is mirrored to `~/projects/ScaleOp` and run with `uv`.

## Deviations from the plan (all intentional)

- **uv instead of pip/venv+requirements.txt** — matches the Spark's established per-project pattern; env is pinned in `pyproject.toml` + `uv.lock`. `requirements.txt` was dropped to keep one dependency source.
- **transformers 5.14.1** (plan floor is 4.40) — the Spark's proven stack. Used `dtype=` (5.x) instead of the deprecated `torch_dtype=`.
- **`lm-eval` deferred to M3** — it isn't needed until behavioral eval and can pin an older transformers, so it lives in the `eval` extra rather than the base env.
